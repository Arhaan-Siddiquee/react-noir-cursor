# React Noir Cursor 🖱️

[![npm version](https://badge.fury.io/js/react-noir-cursor.svg)](https://badge.fury.io/js/react-noir-cursor)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Bundle Size](https://img.shields.io/bundlephobia/minzip/react-noir-cursor)](https://bundlephobia.com/package/react-noir-cursor)

A sleek, customizable cursor component for React applications with elegant hover effects and animations.

## Features ✨
- 🎨 Fully customizable size, color, and behavior
- ✨ Smooth animations and transitions
- 🔍 Hover detection with text display
- 🌈 Multiple blend modes for different backgrounds
- ⚡️ Lightweight (~5kb gzipped)
- 📱 Mobile-friendly (falls back to default cursor on touch devices)
- 🛠 TypeScript support included

## Installation 📦

```bash
npm install react-noir-cursor
# or
yarn add react-noir-cursor
```
